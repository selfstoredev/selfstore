# AGENTS.md

The rules for this repo live in [CLAUDE.md](CLAUDE.md). They are not
Claude-specific: quality gate, contract, git flow and commit conventions apply
to any agent working here. Read that file first.

Two that are lost most often, so they are repeated here:

- Branches and PRs are named by open-source convention, in English, with NO
  tool prefix - not `claude/`, not `agent/`, not `codex/`. A merge commit
  carries the branch name into the history for good.
- PR titles follow the same convention as commits: English, conventional
  commits, pure ASCII.
